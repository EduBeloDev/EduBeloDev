# Créditos dos ícones

Os ícones desta pasta foram gerados a partir do [Devicon](https://github.com/devicons/devicon)
(licença MIT, Copyright (c) 2015 konpa), convertidos para PNG. As cores de alguns ícones
foram ajustadas para ficarem legíveis no tema escuro do GitHub (`github-white`, `bash-white`,
`rust` e `mysql`). Os logos são marcas registradas de seus respectivos donos.
